# Scope

This repository is the **public first-look pack** for the Synrix OEM memory kernel.

It ships `libsynrix.so` (binary only), `make first-look`, and `make receipt`. It
does not ship PHI, BEP, SCM, or behavioral-evidence research.

It also ships **no pre-computed results**. Every number the demo prints is
measured by the shipped binary at run time and written to a receipt generated on
your machine. Retrieval research exists in the private tree and is deliberately
not claimed here, because it is not produced by this binary.

Kernel source and research trees live in the private Synrix monorepo.
